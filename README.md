# Coffee House Menü

Bu proje, Mobil Uygulama Geliştirme dersi kapsamında Flutter kullanılarak geliştirilmiş basit bir kahve katalog uygulamasıdır.

## Proje Hakkında

Uygulama içerisinde farklı kahve çeşitleri listelenmektedir. Kullanıcılar ana ekrandaki ürün kartlarına tıklayarak seçilen kahvenin detay sayfasına geçebilir, ürün bilgilerini görüntüleyebilir ve ürünü sepete ekleyebilir.

## Kullanılan Yapılar

- Flutter
- Dart
- GridView
- Navigator
- Stateful Widget
- Stateless Widget
- Model Sınıfı
- Asset Yönetimi
- Listeleme İşlemleri

## Uygulama Özellikleri

- Kahve ürünlerinin listelenmesi
- GridView ile kart görünümü
- Ürün detay ekranı
- Sayfalar arası geçiş
- Sepete ekleme simülasyonu
- Ürün modeli kullanımı
- Asset klasöründen görsel kullanımı
- Basit ve kullanıcı dostu arayüz

## Proje Yapısı

```text
lib
│
├── data
│   └── products.dart
│
├── models
│   └── product.dart
│
├── screens
│   ├── home_screen.dart
│   └── detail_screen.dart
│
└── main.dart
```

## Kullanılan Ürünler

- Espresso
- Latte
- Americano
- Mocha
- Cappuccino

## Çalıştırma Adımları

1. Projeyi bilgisayarınıza indirin.
2. Terminali proje klasöründe açın.
3. Aşağıdaki komutları çalıştırın.

```bash
flutter pub get
flutter run
```
